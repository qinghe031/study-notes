## 代码

```ts
export function readingMinutes(body: string): number {
  const cjk = (body.match(/[一-鿿]/g) || []).length;
  return Math.max(1, Math.round(cjk / 400));
}
```

## 公式

贝叶斯公式:

$$
P(A \mid B) = \frac{P(B \mid A)\,P(A)}{P(B)}
$$
