这篇讲两件事:**把网站放到网上**(只做一次),以及之后**怎么在线编辑**(每天用)。全程不花钱,不需要买服务器或域名。

## 一、原理一句话

你的网站是"静态"的:笔记是文件,构建一次就变成一堆网页。所以"在线编辑"的本质是——**把文件放到 GitHub 上,在 GitHub 的网页编辑器里改文件,改完 GitHub 自动帮你重新构建并发布**。

项目里已经放好了自动构建的配置(`.github/workflows/deploy.yml`),你只要把代码推上去、开一个开关就行。

## 二、第一次上线(约 10 分钟,只做一次)

### 第 1 步:注册 GitHub 并创建仓库

1. 到 [github.com](https://github.com) 注册(已有账号跳过)。
2. 点右上角 **+ → New repository**。
3. 仓库名填 `study-notes`(或你喜欢的英文名),选 **Public**,其他都不勾,点 **Create repository**。

> 想让网址更短?仓库名填 `你的用户名.github.io`,网址就是 `https://你的用户名.github.io`。否则网址是 `https://你的用户名.github.io/study-notes/`。两种都行,配置会自动识别。

### 第 2 步:把项目推上去

在项目目录打开终端(文件夹地址栏输入 `cmd` 回车),依次运行——把 `你的用户名` 换成你的:

```bash
git init
git add .
git commit -m "第一次提交"
git branch -M main
git remote add origin https://github.com/你的用户名/study-notes.git
git push -u origin main
```

第一次 `push` 会弹窗让你登录 GitHub,登录即可。

> 没装 Git?到 [git-scm.com](https://git-scm.com) 下载安装,一路下一步。

### 第 3 步:打开 Pages 开关

1. 打开你的仓库页面,点 **Settings**(设置)。
2. 左侧点 **Pages**。
3. **Source** 选 **GitHub Actions**。

就这样。回到仓库首页点 **Actions** 标签,能看到一个正在跑的任务,大约 1~2 分钟变绿。

### 第 4 步:访问

绿了之后,网址就是:

- 仓库叫 `study-notes` → `https://你的用户名.github.io/study-notes/`
- 仓库叫 `你的用户名.github.io` → `https://你的用户名.github.io/`

发这个网址给任何人都能看。

## 三、之后怎么在线编辑(每天用)

### 方式 A:直接在网站上写(最简单,推荐)

打开你的网站,顶栏有「✎ 写笔记」,每篇笔记右上角有「编辑这篇」。**第一次**点保存时会让你设置一个 GitHub 令牌(只需一次):

1. 它会自动打开 GitHub 的令牌生成页面
2. **Repository access** 选 "Only select repositories" → 勾选 `study-notes`
3. **Permissions → Repository permissions → Contents** 选 **Read and write**
4. 点 Generate token,复制那串以 `github_pat_` 开头的文字
5. 回到网站粘贴进去

之后写笔记 → 点保存 → 自动提交到仓库 → **等 1~2 分钟**网站更新。令牌只存在你自己的浏览器里,别人访问你的网站看不到写作按钮。

> 本地 `npm run dev` 时也是同一个按钮,但保存是即时的,不用等。

### 方式 B:GitHub 网页编辑器

适合批量改、传图片。打开仓库页面,**按一下键盘上的 `.` 键**,浏览器里会打开一个完整的 VS Code。改完点左侧「源代码管理」→ 填说明 → **✓ 提交并推送**。

### 方式 C:直接在 GitHub 页面上改

适合只改几个字:进入文件,点右上角铅笔图标,改完点 **Commit changes**。

### 方式 D:本地改完推上去

```bash
git add .
git commit -m "说明"
git push
```

### 怎么上传图片(在线)

用方式 B,把图片直接**拖进** `src/content/notes/images/`(笔记配图)或 `public/gallery/相册名/`(相册照片),然后在 Markdown 里引用 `./images/文件名.jpg`。

## 四、发布前的两个建议

**隐藏后台页面。** `/admin/` 不在导航里,但知道地址的人能打开。它不能改你的文件(只是生成文本),所以没有安全风险,但如果不想让人看到,把 `src/pages/admin.astro` 改名为 `_admin.astro`(前面加下划线,Astro 会跳过它)。本地需要时再改回来。

**开启评论和在线留言(可选)。** 现在网站已经在 GitHub 上了,接 Giscus 只要 3 分钟:仓库 Settings → General → Features 勾选 **Discussions**;到 [giscus.app](https://giscus.app) 填仓库名、生成配置;把 `repo` / `repoId` / `categoryId` 填进 `src/data/interactions.json`,把 `comments.provider` 和 `guestbook.provider` 改成 `"giscus"`。

## 五、常见问题

**Actions 跑红了(失败)?**
点进去看日志,最常见的是笔记头信息格式错(日期不合法、tags 没加方括号)。日志里会标出是哪个文件。

**网站显示了但样式全没?**
确认 Settings → Pages → Source 选的是 **GitHub Actions**,不是 "Deploy from a branch"。

**改了文件但网站没变?**
看 Actions 是否跑完;跑完后强制刷新(`Ctrl + F5`)。

**想换成自己的域名?**
买一个域名(一年几十块),在 Settings → Pages → Custom domain 填上,按提示在域名商那里加一条 DNS 记录。GitHub 会自动配 HTTPS。这一步完全可选。

**还是想离线发给别人?**
依旧可以:本地运行 `npm run build:local`,把 `dist-local/` 打包发过去。线上和离线两种方式互不影响。
